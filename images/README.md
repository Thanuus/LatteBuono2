## Como adicionar as imagens pendentes

As imagens pendentes podem ser baixadas manualmente do Instagram:

1. Acesse https://www.instagram.com/lattebuono/
2. Clique nos highlights "Búfalos🐃🌾" para ver as fotos das búfalas
3. Salve as imagens como `fazenda.jpg` e `bufalas.jpg`
4. Para o logo, salve a foto do perfil como `logo-latte-buono.jpg`

Ou envie as imagens diretamente para a pasta `images/`.

## Formato das imagens

- **Formato:** JPG para fotos, PNG para logo
- **Otimização:** Comprima as imagens para web (use ferramentas como TinyPNG ou Squoosh)
- **Tamanho máximo recomendado:** 500KB por imagem
